## How Domestika discount codes actually work

Domestika handles codes at checkout, in a browser. Add your courses to the cart, go to checkout, and click the link that says "Do you have a discount code?" — a box opens, you paste the code, hit Apply, and the total drops before you pay. Domestika's support pages confirm this flow, and they also confirm two things people get wrong constantly:

- **A code can't be added after payment.** Once the order is complete, the discount is gone. If the code fails at checkout, fix it before paying, not after.
- **One code per order, no stacking.** If a code isn't working, it's often because another discount is already applied — you have to remove it (click the "X" next to the applied discount in the cart or order summary) before a new one will take.

There's also a format quirk worth knowing: if your "code" looks like `xxxx-xxxx-xxxx-xxxx`, it isn't a discount code at all. That's a gift code for a course someone sent you, and it gets redeemed through a separate gift process rather than the checkout box.

## What Domestika discount codes can't be used on

This is where most coupon-site articles stop short, and where people waste the most time. Domestika's own terms list the exclusions explicitly. Discount codes are **not accumulative** and cannot be applied to:

- Bundle purchases (the "create your own bundle" multi-course deals)
- Domestika Plus subscriptions (unless a specific promotion says otherwise)
- Plus credits
- Gift cards
- Any purchase made in the mobile app

The app exclusion matters more than it sounds. Domestika runs frequent in-app offers, but if you buy a course through the mobile app, no code will work — you need to complete the purchase in a browser for the code box to even exist.

So the realistic use case for a code is narrow: a single, full-price (or already-discounted) course bought on the website. That's it. Codes still work on courses that are already on sale, which is useful during Domestika's frequent sitewide sales — but it's one or the other, never code on top of sale price plus bundle discount.
